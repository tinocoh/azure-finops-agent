# Project plan

## Goals

- Publish Azure FinOps Agent as a standards-compliant Azure sample.
- Keep the repository compatible with Azure Developer CLI (`azd`).
- Demonstrate secure, keyless Azure OpenAI and FinOps patterns.
- Keep documentation, UI, and metadata in English for public review.

## Workstreams

1. Repository readiness for Azure-Samples and Microsoft OSS review.
2. `azd` template compatibility and infrastructure validation.
3. Agent and MCP integration.
4. Security hardening and audit-safe defaults.
5. Dependency hygiene and CI validation.

## Current status

- Public staging repository exists at `tinocoh/azure-finops-agent`.
- OSS Portal release pre-approval was submitted.
- Azure-Samples submission path is paused pending issue #46 in `Azure-Samples/azd-template-artifacts`.
- CI and `Validate AZD template` workflows are passing.
