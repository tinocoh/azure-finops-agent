# V2 roadmap

## Candidate improvements

- Add first-class localization support with English as the default locale.
- Add richer FinOps reporting exports.
- Add optional ingestion of customer-owned policy or guidance documents.
- Add deeper Azure Advisor and reservations analysis.
- Add evaluation datasets for generated recommendations.
- Add stronger data minimization and masking controls for regulated deployments.
- Add end-to-end hosted deployment validation after App Service quota is available.

## Governance

All roadmap items should preserve:

- Read-only default behavior.
- Managed identity and RBAC access patterns.
- Azure Developer CLI compatibility.
- Public sample documentation in English.
- Human review before applying any production optimization.
