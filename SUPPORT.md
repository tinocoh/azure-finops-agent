# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/Azure-Samples/azure-finops-agent/issues) to
track bugs and feature requests. Please search the existing issues before filing a new one to avoid
duplicates. For new issues, file your bug or feature request as a new issue using the
[issue templates](https://github.com/Azure-Samples/azure-finops-agent/issues/new/choose).

For help and questions about using this project, please open a
[discussion](https://github.com/Azure-Samples/azure-finops-agent/discussions) or a question issue.

## Microsoft Support Policy

Support for this project is limited to the resources listed above. This is a sample intended to
demonstrate Azure services and patterns; it is **not** a supported Microsoft product and carries no
service level agreement. For production support of the underlying Azure services, use your existing
[Azure support plan](https://azure.microsoft.com/support/plans/).

## Security issues

Do not report security vulnerabilities through GitHub Issues. See [SECURITY.md](SECURITY.md).
